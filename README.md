# 酷鸟云 VPS 增强助手 (Kuniao VPS Enhancement Helper)

一个用于酷鸟云 VPS 的增强脚本，旨在通过自动化流程提升运维效率。
An enhanced script for Kuniao VPS, designed to improve maintenance efficiency through automation.

---

## 🚀 功能说明 / Features

- **智能匹配与填充 (Smart Auto-fill)**：根据当前 VPS 链接自动匹配对应密码，自动填充并提交登录表单。
- **全自动流程 (Auto-Workflow)**：登录成功后自动点击“进入远程”按钮。
- **标签页优化 (Tab Optimization)**：
    - **标题重命名**：自动将浏览器标签页标题修改为 VPS 编号（若已设置），方便多开时快速辨识。
    - **标题同步**：Automatically modify the browser tab title to the VPS ID (if set) for easier identification.
- **标签页管理 (Tab Management)**：打开远程控制页面后，尝试自动关闭旧的登录标签页。
- **独立密码映射 (Isolated Storage)**：为每个 VPS 地址独立保存密码映射，互不干扰。
- **便捷交互 (Interactive UI)**：
    - **悬浮面板**：支持拖动、左右吸附及状态显示。
    - **手动新增**：支持在面板中手动输入 VPS 信息并添加记录。
    - **安全删除**：删除记录前增加确认步骤，防止误操作。
    - **动态操作**：通过面板更新、删除或直接跳转至已保存的 VPS 地址。

---

## 📖 使用方式 / How To Use

1. **唤起面板**：安装脚本后，在支持的 VPS 页面右下角会显示一个悬浮按钮。
2. **管理密码**：点击悬浮按钮即可打开管理面板进行以下操作：
    - **新增**：为当前地址或手动输入新地址的新增登录密码。
    - **更新**：更新已有地址的密码记录。
    - **删除**：移除不再需要的映射关系（需点击二次确认）。
    - **快速跳转**：点击列表中已存储的项目，快速跳转至对应的 VPS 地址。
3. **自动化体验**：当再次访问已保存的 VPS 链接时，脚本将自动完成从“匹配 -> 登录 -> 进入远程 -> 修改标题”的全过程。

---

## 🎯 适用场景 / Use Cases

适用于需要频繁管理/打开多个酷鸟云 VPS 链接的场景。通过自动管理不同地址的登录凭据并清晰化标签页标题，大幅减少重复的输入与手动切换成本。

---

## ⚠️ 注意事项 / Notes

- **数据安全**：密码映射保存在本地油猴（Userscript）存储中，请妥善保管您的本地数据。
- **防误删机制**：执行删除操作时请注意弹窗确认，一旦删除需重新手动录入。
- **浏览器权限**：
    - 自动打开远程页面功能可能需要您在浏览器设置中**允许弹出窗口**。
    - 脚本关闭旧标签页的行为受浏览器安全策略限制，可能在某些环境下失效。
- **兼容性说明**：若酷鸟云官方调整页面结构（如 ID 或 Class 变更），脚本识别登录框或“进入远程”按钮的逻辑可能需要随之更新。
